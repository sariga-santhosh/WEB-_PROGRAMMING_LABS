WEB TECHNOLOGY

Web Technology refers to the tools, techniques, programming languages, and protocols used to create, develop, and maintain websites and web applications. It enables communication between users and web servers through the Internet.
It involves:

  • Client/Server
  • Components of Web Application
  • Types of Web Content
  • HTTP and HTTP Request
  • Dynamic Web Pages
  • Application Servers
  • Web Security

Client/Server

Client: A program or device that requests services,data or resources from another program. It initiates communication. Examples: web browser,mobile app,email client
Server: A program or device that listens for requests and provides services, data, or resources in response. It waits for and responds to clients. Examples: web server, database server, file server

Components of Web Application

View Layer (Presentation Layer): The part of a web application that the user directly interacts with. It handles the display of information and the user interface, typically built with HTML, CSS, and JavaScript.
Business Layer (Logic Layer): The layer that processes the core functionality and business rules of the application. It acts as a bridge between the view layer and the data access layer, handling calculations, validations, and decision-making logic.
Data Access Layer: The layer responsible for communicating with the database or data storage system. It handles operations like retrieving, inserting, updating, and deleting data.

Types of Web Content

  • Text Written content such as articles, paragraphs, and headings displayed on a webpage.
  • Images Visual content in formats like JPEG, PNG, or GIF used to enhance and illustrate webpages.
  • Audio Sound files embedded in webpages, such as music or voice recordings, usually in formats like MP3 or WAV.
  • Video Moving visual content with or without sound, embedded using formats like MP4.
  • Animation Content that creates the illusion of motion, often using CSS, JavaScript, GIFs, or SVG.

HTTP and HTTP Request

HTTP (HyperText Transfer Protocol): A protocol used for transmitting hypertext (web pages) between a client (browser) and a server over the internet. It defines rules for how messages are formatted and transmitted.
HTTP Request and Response An HTTP request is a message sent by the client to the server asking for a resource (e.g., a webpage). An HTTP response is the message sent back by the server, containing the requested data or an error/status message.
Working of HTTP Communication: The client sends an HTTP request to the server specifying the desired action (like GET or POST); the server processes the request and returns an HTTP response with a status code (e.g., 200 OK) and the requested content, completing the communication cycle.

Dynamic Web Pages

Definition: A dynamic web page is a webpage whose content can change based on user interaction, input, or other factors, often generated in real-time using server-side or client-side scripting.


Characteristics:
  • Content changes based on user input or database data
  • Requires scripting languages (e.g., PHP, JavaScript, Python)
  • Interacts with databases
  • Personalized content for different users

Examples: Social media feeds (Facebook, Instagram), online shopping sites (Amazon), email services (Gmail), and search engines (Google).

Application Servers

Definition: An application server is a software framework that provides an environment for running and managing web applications, handling business logic between users and backend databases/services.

Purpose: To execute application code, manage transactions, and provide services like security, load balancing, and connectivity between the client and the database.

Major Services: Transaction management, security and authentication, load balancing, database connection pooling, session management, and messaging services.

Web Security

Definition: Web security refers to the measures and protocols implemented to protect websites and web applications from cyber threats, unauthorized access, and data breaches.

Importance: Protects sensitive user data, maintains user trust, prevents financial loss, ensures business continuity, and complies with legal/regulatory requirements.

Basic Security Measures:
  • Using HTTPS/SSL encryption
  • Strong password policies and authentication
  • Regular software updates and patches
  • Input validation to prevent SQL injection/XSS attacks
  • Firewalls and intrusion detection systems
  • Regular data backups
