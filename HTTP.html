HTTP

Definition of HTTP

HTTP stands for HyperText Transfer Protocol. It is a protocol used for communication between web clients and web servers.

HTTP Request and Response

An HTTP request is sent by a client to request a resource from a server. The server processes the request and returns an HTTP response.

Working of HTTP Communication

  1. The browser sends an HTTP request.
  2. The request reaches the web server.
  3. The server processes the request.
  4. The server sends an HTTP response.
  5. The browser displays the result.
