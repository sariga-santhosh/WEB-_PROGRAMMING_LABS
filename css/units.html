CSS Units

CSS units are used to specify sizes such as width, height, margin and font size.

Common Units

  • px – Pixels
  • % – Percentage
  • em – Relative to the font size
  • rem – Relative to the root font size
  • vw – Viewport width
  • vh – Viewport height
  • cm – Centimeters
  • mm – Millimeters
  • in – Inches
